## Visual Hierarchy & Focal Points

- **Main Screen Focal Point**: The checklist trigger tag and the BESST status badge in the table row serve as the primary visual anchors. They guide the investor's focus directly to the checklist verification state and defensive status of each asset.
- **Checklist Modal Focal Point**: The modal header, prominently displaying the asset ticker and company name (e.g. `PETR4 — Petróleo Brasileiro S.A.`), serves as the central visual anchor, ensuring the user immediately identifies the target of their checklist configuration.

## UI Components & Interaction Contract

### 1. BESST Sector Filter Dropdown
- **Placement**: Add as a separate `<select>` dropdown next to the existing status filter in the toolbar.
- **Options**:
  - `Todos os Setores` (default)
  - `Apenas BESST` (filters to show only sectors in: Bancos, Energia, Saneamento, Seguros, Telecom)
  - `Sem Setor` (filters to show assets with `sector = null` or empty)
  - Individual sectors: dynamically populated based on active sectors in database.
- **Filter logic**: Combines with the existing Status filter using logic AND.
- **BESST Badge**: Tracked assets belonging to a BESST sector should show a protective shield icon (inline SVG) next to their sector name.

### 2. Barsi Checklist Modal Overlay
- **Trigger**: Clickable qualitative tag or button labeled "Checklist" or "Validar" placed in the Actions column of the assets table (next to "Dividendos" details wrapper).
- **Technology**: Native HTML `<dialog>` tag to utilize browser-native focus-trapping and keyboard controls (Escape key closes window).
- **Structure**:
  - **Header**: Displays Asset Ticker and Company Name (e.g. `PETR4 — Petróleo Brasileiro S.A.`).
  - **Sector Selection**: Dropdown select listing standard sectors (Bancos, Energia, Saneamento, Seguros, Telecom, Outros) and allowing manual text entry if "Outro" is chosen.
  - **Checklist Form Grid**:
    - **Profitable (Lucro Consistente)**: "Histórico de lucros constantes e sem prejuízos recentes." -> Radio buttons: `Sim`, `Não`, `Não sei` (pre-selected to `Não sei` if never saved).
    - **Stable Debt (Dívida Saudável)**: "Endividamento equilibrado and sob controle." -> Radio buttons: `Sim`, `Não`, `Não sei`.
    - **Sustainable Payout (Dividendo Sustentável)**: "Histórico de payout sustentável e recorrente." -> Radio buttons: `Sim`, `Não`, `Não sei`.
  - **Footer Action Buttons**:
    - "Salvar Checklist" button (Accent fill `#2457a6`, white text) -> Submits checklist payload via PUT.
    - "Descartar Alterações" button (border style, secondary text) -> Closes modal without saving.
